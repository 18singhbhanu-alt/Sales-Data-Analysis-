# Sales Dashboard Analysis 📊

## Overview
This project presents a comprehensive Sales Dashboard created using Power BI.  
The dashboard analyzes sales performance, profit trends, customer segments, product categories, and regional insights for the years 2014–2017.

The goal of this project is to transform raw sales data into meaningful business insights using data visualization techniques.

---

## Project Highlights
- Sales Trend Analysis (2014–2017)
- Regional Profit Analysis
- Segment-wise Sales Distribution
- Sub-category Quantity Analysis
- Top Performing Products
- Interactive Dashboard Visualizations
- Business Insights & Performance Tracking

---

## Tools & Technologies Used
- Power BI
- Microsoft Excel
- Data Cleaning
- Data Visualization
- Business Analytics

## Dashboard Features

### 1. Executive Summary
- Total Sales
- Total Profit
- Total Orders
- Average Discount
- Total Quantity Sold

### 2. Sales Trend Analysis
- Year-wise Sales Performance
- Quarterly Sales Tracking
- Peak & Declining Sales Periods

### 3. Product Category Analysis
- Quantity Sold by Sub-category
- Top Performing Product Categories

### 4. Segment Analysis
- Consumer Segment Performance
- Corporate Segment Insights
- Home Office Sales Distribution

### 5. Regional Profit Analysis
- Profit by Region
- Loss-making Regions Identification
- Regional Comparison

### 6. Top Products Analysis
- Highest Sales Products
- Product Profitability
- Discount Impact on Profit

---

## Key Insights
- Highest sales were recorded in 2015.
- West region generated the highest profit.
- East region faced the largest losses.
- Consumer segment contributed the highest sales quantity.
- High discounts negatively affected profit margins.
